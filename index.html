Research

My PhD is about the software between a control engineer's model and the computer that runs the controller. Today a model with a neural network inside, solved by a dedicated optimizer, crosses several tools and runtimes before it reaches a robot, and each boundary costs speed. I build compilers that see the whole problem at once.

scaly

A modelling and code-generation library for optimal control. You describe dynamics, costs and constraints once in Python, and scaly generates self-contained C code for them and their sparse derivatives, ready for solvers such as IPOPT and PIQP. Repeated stages stay loops, so the code stays small as the horizon grows.

Against CasADi, its generated derivatives are 1.8 to 53 times faster in closed-loop benchmarks, and it still compiles problems that CasADi cannot.
